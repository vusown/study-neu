## 1. Đề thi ra gì và ưu tiên học

| Phần | Điểm / số câu | Dạng | Lấy từ |
|---|---|---|---|
| Trắc nghiệm | 8 câu × 0,5 = 4đ | Chọn 1 trong 4: tính nhanh giới hạn, đạo hàm, tích phân, đạo hàm riêng; nhận biết khái niệm | Cả 12 bài; câu LTTN, KT trên hệ thống |

Ma trận đề: **Nhớ 40% · Hiểu 40% · Vận dụng 20%**. Vận dụng = **Bài 4–5** (ứng dụng đạo hàm) và **Bài 11–12** (cực trị hàm nhiều biến), cộng câu tổng hợp (tối ưu kinh tế, ứng dụng tích phân, hàng hoá bổ sung/thay thế). Chưa có đề thật, **cần xác minh**.

**Ưu tiên học:**
1. **Tối ưu một biến (Bài 4–5):** cực trị, lợi nhuận tối đa (R' = C'), chi phí bình quân tối thiểu (A = C'), độ co giãn của cầu và doanh thu.
2. **Cực trị hai biến (Bài 11–12):** điểm tới hạn + D; nhân tử Lagrange; ý nghĩa λ.
3. **Ứng dụng tích phân (Bài 7):** thặng dư tiêu dùng, thặng dư sản xuất, Gini, PV/FV dòng thu nhập, lợi nhuận vượt trội ròng.
4. **Kỹ năng tính (Bài 2, 3, 6, 8, 10):** quy tắc đạo hàm, hàm hợp, hàm ẩn, cận biên và xấp xỉ, tích phân đổi biến, từng phần, đạo hàm riêng và cận biên hai biến.
5. **Bài 1, 9:** mô hình hàm số, giới hạn, cân bằng và hoà vốn; tính gần đúng tích phân, tích phân suy rộng.

## 2. Cách học

### Học theo dạng bài, không học theo số thứ tự
Mở [ngan-hang-theo-chu-de.md](ngan-hang-theo-chu-de.md), học từng chủ đề. Mỗi chủ đề là một dạng bài.

### Mỗi chủ đề làm 3 bước
1. Đọc dòng 🔑 **Ghi nhớ**: công thức và các bước giải.
2. Che lời giải, **tự giải ra giấy** từng câu: viết công thức trước, thay số sau.
3. So với lời giải. Sai bước nào thì đánh dấu ❌ vào câu, hôm sau giải lại.

### Luyện tay, không chỉ đọc
Môn toán không học thuộc được bằng đọc. Mỗi ngày giải lại ít nhất 5 bài cũ, có bấm giờ (tự luận khoảng **12 phút/câu**).

### Câu trắc nghiệm hệ thống
Khi có câu LTTN, KT thì giải lại ra kết quả, không nhớ chữ cái A/B/C/D (thứ tự phương án bị xáo). Phương án nhiễu thường là kết quả của một lỗi hay gặp ở mục 5.

## 3. Các bước giải chuẩn cho từng dạng bài

### Cận biên và xấp xỉ (Bài 3)
1. Viết hàm cần dùng (R = x·p(x), P = R − C).
2. Đạo hàm: MC = C'(x), MR = R'(x), MP = P'(x).
3. Đơn vị thứ x₀ + 1: ước tính ≈ C'(x₀); thực tế = C(x₀ + 1) − C(x₀).
4. Xấp xỉ: Δf ≈ f'(x₀)·Δx; % thay đổi ≈ 100·f'(x₀)·Δx / f(x₀).
5. Kết luận có đơn vị.

### Tốc độ liên quan (Bài 3)
1. Đặt biến, ghi các đại lượng là hàm của t.
2. Viết phương trình liên hệ, tìm giá trị còn thiếu (thay số vào phương trình gốc).
3. Đạo hàm hai vế theo t (hàm hợp, quy tắc tích).
4. Thay số **sau khi** đạo hàm, giải ra tốc độ cần tìm.

### Cực trị và tính lõm một biến (Bài 4)
1. Tập xác định.
2. f'(x), số tới hạn (f' = 0 hoặc không xác định, phải thuộc tập xác định).
3. Bảng xét dấu f' → khoảng tăng/giảm, cực đại/cực tiểu (hoặc dấu f'').
4. f'', điểm f'' = 0 hoặc không xác định, xét dấu → khoảng lõm, điểm uốn (ghi đủ toạ độ).

### Tối ưu kinh tế một biến (Bài 5)
1. Đại lượng cần tối ưu và biến; miền của biến (đóng hay mở, có cận thực tế không).
2. Viết hàm một biến (P = R − C, A = C/q, R = p·q…).
3. Đạo hàm, số tới hạn; so giá trị tại số tới hạn và **mút** (đoạn đóng) hoặc dùng f'' (số tới hạn duy nhất).
4. Kiểm tra số nguyên nếu biến là người, sản phẩm.
5. Trả lời đúng câu hỏi, có đơn vị (đổi "nghìn", "trăm").

### Độ co giãn (Bài 5)
1. E(p) = −(p/q)·(dq/dp), q = D(p).
2. Thay p, so E với 1: > 1 co giãn, < 1 không co giãn, = 1 đơn vị.
3. Doanh thu: E < 1 tăng giá thì R tăng; E > 1 tăng giá thì R giảm.

### Tích phân và ứng dụng (Bài 6–8)
1. Viết đúng tích phân (cận, hàm dưới dấu tích phân, đơn vị).
2. Tìm nguyên hàm (bảng cơ bản, đổi biến, từng phần, bảng tích phân).
3. Thay cận F(b) − F(a).
4. Diễn giải: diện tích, thay đổi ròng, CS/PS, Gini, PV/FV.

### Cực trị hai biến không điều kiện (Bài 11)
1. fₓ, f_y; giải hệ fₓ = 0, f_y = 0 → **đủ** các điểm tới hạn.
2. fₓₓ, f_yy, fₓ_y; D = fₓₓ·f_yy − (fₓ_y)².
3. Từng điểm: D < 0 yên ngựa; D > 0 và fₓₓ > 0 cực tiểu; D > 0 và fₓₓ < 0 cực đại; D = 0 không kết luận.
4. Tính giá trị f tại điểm cực trị, kết luận theo câu hỏi.

### Cực trị có điều kiện, Lagrange (Bài 12)
1. Đưa ràng buộc về g(x, y) = k.
2. Hệ fₓ = λgₓ, f_y = λg_y, g = k (ba biến thì thêm f_z = λg_z).
3. Khử λ (chia hai phương trình), thế vào ràng buộc. Tách trường hợp x = 0 / λ = 1, không chia cho biến.
4. Tính f tại mọi nghiệm, so sánh lấy lớn nhất/nhỏ nhất.
5. Ý nghĩa λ: k tăng 1 đơn vị thì giá trị tối ưu thay đổi ≈ λ.

## 4. Bảng phải thuộc lòng

### Đạo hàm

| Hàm | Đạo hàm |
|---|---|
| c | 0 |
| xⁿ | n·xⁿ⁻¹ (mọi số thực n) |
| eˣ · eᵏˣ | eˣ · k·eᵏˣ |
| ln x · ln u(x) | 1/x · u'/u |
| f·g | f'·g + f·g' |
| f/g | (f'·g − f·g')/g² |
| f(u(x)) | f'(u)·u'(x) (hàm hợp: dy/dx = dy/du · du/dx) |

### Tích phân

| Hàm | Nguyên hàm |
|---|---|
| xⁿ (n ≠ −1) | xⁿ⁺¹/(n + 1) + C |
| 1/x | ln\|x\| + C |
| eᵏˣ | eᵏˣ/k + C |
| Đổi biến | u = g(x), du = g'(x)dx; tích phân xác định thì **đổi cận** |
| Từng phần | ∫u dv = uv − ∫v du; có ln x thì chọn u = ln x; x·eᵏˣ thì chọn u = x |
| Định lý cơ bản | ∫ₐᵇ f(x) dx = F(b) − F(a) |

### Công thức kinh tế

| Đại lượng | Công thức |
|---|---|
| Doanh thu, lợi nhuận | R = x·p(x); P = R − C |
| Chi phí bình quân | A(q) = C(q)/q; tối thiểu khi **A = C'** |
| Lợi nhuận tối đa | **R'(q) = C'(q)** và R''(q) < C''(q) |
| Cận biên | MC = C'(x₀) ≈ C(x₀ + 1) − C(x₀) (chi phí đơn vị thứ x₀ + 1) |
| Xấp xỉ, % thay đổi | Δf ≈ f'(x₀)·Δx; % ≈ 100·f'(x₀)·Δx / f(x₀); vi phân dy = f'(x)dx |
| Tốc độ % | 100·Q'(x)/Q(x) |
| Độ co giãn của cầu | **E(p) = −(p/q)·(dq/dp)**; R'(p) = q·[1 − E(p)] |
| Diện tích giữa 2 đường | ∫ₐᵇ [trên − dưới] dx |
| Lợi nhuận vượt trội ròng | NE = ∫₀ᴺ [P₂'(t) − P₁'(t)] dt, N là lúc P₁' = P₂' |
| Chỉ số Gini | GI = 2∫₀¹ [x − L(x)] dx (0 ≤ GI ≤ 1, nhỏ hơn là công bằng hơn) |
| Giá trị trung bình | V = (1/(b − a))∫ₐᵇ f(x) dx |
| Dòng thu nhập (lãi liên tục) | FV = ∫₀ᵀ f(t)e^{r(T − t)} dt; PV = ∫₀ᵀ f(t)e^{−rt} dt |
| Mức sẵn lòng chi tiêu | WS = ∫₀^{q₀} D(q) dq |
| Thặng dư | CS = ∫₀^{q₀} D(q) dq − p₀q₀; PS = p₀q₀ − ∫₀^{q₀} S(q) dq |
| Hình thang, Simpson | Tₙ = (Δx/2)[1, 2, …, 2, 1]; Sₙ = (Δx/3)[1, 4, 2, …, 4, 1], n chẵn; Δx = (b − a)/n |
| Tích phân suy rộng | ∫ₐ^{+∞} f dx = lim_{N→+∞} ∫ₐᴺ f dx; lim_{N→+∞} Nᵖe^{−kN} = 0 (k > 0) |
| Sản lượng cận biên | Q_K, Q_L: Q tăng ≈ bao nhiêu khi K (hoặc L) tăng 1, biến kia giữ nguyên |
| Cobb-Douglas | Q = A·K^α·L^β, α + β = 1 ⟹ tăng gấp đôi K và L thì Q gấp đôi |
| Thay thế / bổ sung | ∂D₁/∂p₂ > 0 **và** ∂D₂/∂p₁ > 0: thay thế; cả hai < 0: bổ sung; trái dấu: không phải loại nào |
| Hàm hợp hai biến | dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt) |
| Xấp xỉ hai biến | Δz ≈ (∂z/∂x)·Δx + (∂z/∂y)·Δy |
| Cực trị hai biến | D = fₓₓ·f_yy − (fₓ_y)² |
| Lagrange | fₓ = λgₓ, f_y = λg_y, g = k; λ = dM/dk |

## 5. Bẫy hay gặp và quy luật đáp án

Đã có câu LTTN hệ thống (Bài 2, 3, 5, 6 và 2 lượt tổng hợp Tuần 9, phủ gần hết Bài 1–12). Bảng dưới gồm lỗi hay gặp rút từ ví dụ bài giảng và từ các câu hệ thống; phương án nhiễu trắc nghiệm thường rơi vào đây.

| Bẫy | Đúng là |
|---|---|
| Đơn vị thứ 37 | x₀ = **36**: ước tính C'(36), thực tế C(37) − C(36) |
| Chi phí thực tế đơn vị thứ k | tính hiệu **C(k) − C(k−1)**, không ước tính bằng cận biên (hệ thống: đơn vị thứ 100 = C(100) − C(99) = 83.432) |
| Giới hạn dạng 0/0 | phân tích nhân tử, rút gọn rồi mới thay số (không thay số luôn) |
| Giới hạn dài hạn (t → +∞) | mọi số hạng A/(t^k + 1) hay B/(at + b) đều → **0**, chỉ còn hằng số cộng thêm |
| "Tốc độ … thay đổi với tốc độ" | là **đạo hàm cấp hai**, không phải cấp một |
| Khai triển trước khi đạo hàm cấp cao | f(t) = t(2t−1)² phải nhân ra đa thức rồi mới đạo hàm hai lần |
| Xấp xỉ số gia cho đạo hàm cấp hai | ΔP' ≈ P''(t₀)·Δt (áp dụng số gia cho cả tốc độ thay đổi) |
| Nhân tử bình phương (x − a)² | đạo hàm **không đổi dấu** qua x = a ⟹ không phải cực trị dù đạo hàm bằng 0 tại đó |
| f'' = 0 cả hai phía không đổi dấu | **không phải điểm uốn** (ví dụ f'' = k(x − a)² ≥ 0 luôn) |
| Cobb-Douglas, ngân sách p₁x + p₂y = I | phân bổ theo tỷ lệ số mũ: x* = [a/(a+b)]·I/p₁, y* = [b/(a+b)]·I/p₂ (số mũ bằng nhau thì chia đều ngân sách) |
| Hệ số co giãn từ phương trình ẩn | đạo hàm ẩn theo p rồi thế q² = (biểu thức theo p) để đưa về một biến |
| Đọc đồ thị lõm/điểm uốn | các điểm đánh dấu trên đồ thị là nơi bề lõm **đổi chiều**; đếm khoảng xen kẽ lõm lên/lõm xuống giữa các điểm đó |
| Simpson n = 2 với đa thức bậc ≤ 3 | công thức **chính xác tuyệt đối** (không có sai số), dùng để suy ra hệ số k mà không cần biết f cụ thể |
| Câu tham chiếu "trong Câu N" | nếu không có đề của Câu N gốc thì **bỏ qua câu đó**, không đoán số liệu |
| x tính bằng nghìn/trăm | 9,000 sản phẩm → x = 9; đáp số q = 6 nghĩa là **6,000** đơn vị |
| Mốc thời gian | "t năm sau năm 2005", năm 2013 → **t = 8**; quý 1 → Δt = **0.25** |
| % thay đổi | phải **chia f(x₀)** rồi nhân 100 |
| MR | đạo hàm **R = x·p(x)**, không đạo hàm p(x) |
| f''(c) > 0 | **cực tiểu** (lõm lên); f''(c) < 0 là cực đại |
| f''(c) = 0 | chưa chắc điểm uốn, phải xét f'' **đổi dấu** |
| Cực trị trên đoạn | so cả **hai mút** |
| E(p) | dương, so với **1**; E < 1 tăng giá thì **doanh thu tăng** |
| ∫ eᵏˣ dx | **chia** k, không nhân k |
| Đổi biến | quên hệ số du (Bài 6 Ví dụ 5a slide in nhầm 2/3, đúng **1/3**) |
| Diện tích dưới √x·(x+3) | khai triển căn thức thành x^(3/2)+3x^(1/2) **trước** khi lấy nguyên hàm, không giữ nguyên dạng tích |
| Hàm 2 biến có hệ số phân số (1/2)x² | đạo hàm theo x chỉ ra **x** (không phải 2x hay x²) — dễ nhầm với trường hợp hệ số nguyên |
| MPK/MPL Cobb-Douglas | thay đúng biến K vào số mũ của K, L vào số mũ của L — đề mẫu từng thay nhầm vai trò K↔L khiến đáp án không khớp, gặp trường hợp này cứ giữ đáp án hệ thống/đề mẫu |
| Đạo hàm hỗn hợp f_xy có dấu trừ trong đề | đạo hàm từng bước theo đúng dấu của số hạng gốc (vd. −5xy cho fₓy = ... − 5, không phải +5) |
| Đề mẫu/đề thi có lỗi đánh máy (thừa/thiếu dấu) | nếu tính ra đúng giá trị của một phương án nhưng đáp án ghi nhãn kèm dấu khác, lấy **giá trị** làm chuẩn, đáp án hệ thống vẫn thắng về mặt lựa chọn |
| Gini | nhân **2**; Gini nhỏ hơn là công bằng hơn |
| Giá trị trung bình | chia **(b − a)** |
| CS, PS | CS = tích phân − p₀q₀; PS = p₀q₀ − tích phân (ngược nhau) |
| Thay thế / bổ sung | xét **dấu hai đạo hàm chéo** (slide Bài 10 tr. 20 viết định nghĩa bằng lời lệch với tiêu chí) |
| Đạo hàm riêng | biến kia coi là **hằng số**; yˣ theo x là hàm mũ (yˣ ln y), theo y là luỹ thừa (x·yˣ⁻¹) |
| D < 0 | **yên ngựa**, không xét fₓₓ; D = 0 không kết luận |
| Lagrange | đừng quên phương trình **g = k**; x = λx thì tách x = 0 hoặc λ = 1 |
| λ | thay đổi của **giá trị tối ưu**, không phải của x, y |

**Quy luật chung:**
- Kết quả có đơn vị: đọc kỹ "nghìn", "trăm", "cents".
- Nghiệm âm của biến kinh tế (giá, lượng, thời gian) thì loại; ghi rõ bước loại.

## 6. Những cặp dễ nhầm

| Cặp | Phân biệt |
|---|---|
| Tốc độ thay đổi f'(c) / thay đổi thực tế | f'(15) là xấp xỉ; thay đổi trong tháng thứ 16 là **P(16) − P(15)** |
| Tương đối / phần trăm | Q'/Q (0.0977) / 100·Q'/Q (9.77%) |
